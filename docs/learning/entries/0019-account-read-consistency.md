# LEARN-0019 · 버전과 내용을 같은 DB 상태로 읽기

2026-11-13 작성자 구현·합성 재현 관측. 원본 backend BE-AUTH-07/ADR019 및 scripts/check-account-snapshot-db.cjs. 독립 승인/실사용자 장애/성과 측정 아님.

찜 콘텐츠/이벤트/버전을 각각 Promise.all로 읽으면 한 응답에 서로 다른 저장 전후 상태가 섞일 수 있었다. 설정 저장 트랜잭션 뒤에 재조회하면 다른 기기의 후속 저장이 현재 저장 응답으로 돌아올 수 있었다. 임시 PostgreSQL의 두 연결로 각각 결정적인 교차 쓰기를 주입해 이전 코드2실패·수정2통과를 확인했다. 다른 계정 불변도 검사했다.

설정·찜 읽기는 짧은 RepeatableRead 트랜잭션으로, 설정 저장 응답은 자기 쓰기 트랜잭션 안에서 확정한다. 페이지 간 변경은 기존 버전/커서 충돌 검사를 유지한다. 실제Google/폰UI·지연응답·계정전환 전체 흐름 검증을 대체하지 않는다. 제공처 데이터를 더 넣어서는 이 동기화 결함이 해결되지 않는다. 관련 repository/transaction/계약이 바뀌면 주장을 재검토한다.
