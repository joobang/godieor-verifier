# LEARN-0012 · 상세 최신값과 비동기 응답의 소유권

작성자 기술 해설 초안. 원본: app/docs/ai/tasks/APP-01-review-fixes.md, 독립 정적 리뷰: reviews/2026-11-09-app-public-calendar.md.

상세 조회 후 날짜만 최신 응답을 쓰고 상태는 목록 값을 사용하면 하나의 화면에 서로 다른 버전이 섞인다. 표시 객체를 detail.event로 통일했다. EPL은 공개시장 대신 개최국을 가지므로 각 의미에 맞는 필드를 표시한다.

날짜와 필터만 비교하면 같은 선택의 이전 revision 응답을 막을 수 없다. 요청 UUID와 catalogRevision을 함께 검사했다. 처음에는 월 재시도마다 날짜 UUID를 무효화했으나 동일 revision에서 대체 날짜 task가 실행되지 않아 로딩이 남는 경로를 재검토에서 발견했다. 불필요한 무효화를 제거했다. 이 경합은 정적 발견이며 실제 지연 주입 장애로 표현하지 않는다.

작성자 빌드 및 일반 UI 탐색 확인, 별도 정적 재검토에서 추가 지적 없음 보고. 성능 향상·지연 경합 회귀 통과·사용자 학습 완료는 측정하지 않았다. 이후 task/revision 구조 변경 시 본 주장을 재검토한다.
