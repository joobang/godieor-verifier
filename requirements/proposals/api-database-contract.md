# API·DB 계약 독립 검토 제안

- 작업 VFY-01 / SYS-02. 상태: draft/미승인. 승인 acceptance.yaml은 변경하지 않는다.
- 계약 0.1.0-draft.1, backend commit·digest는 docs/contracts/reference.json. 본문은 구현 담당의 제안이며 독립 결과가 아니다.
- 검토자는 고정 파일/제품 정책/공식 근거를 읽고 자체 기대값을 구성한다. 구현 대화나 가상 응답을 정답으로 상속하지 않는다.

| 관찰점 | 기준에서 만들어야 할 반례/기대값 |
|---|---|
| 시간 경계 | UTC→KST 날짜 이동, 날짜만인 값의 날짜 유지, DST 23/25시간, 2026 포함 경계 |
| 범위·페이지 | 2026년보다 먼 미래 허용/62일 폭 제한, 마지막 페이지, 다른 조건 cursor 거부, revision 변경 409 |
| 월 건수 | preview 2개보다 많은 날도 실제 전체 total, 목록/달력 필터·버전 일치, 미정 합계 제외 |
| 시즌/지역/기기 | 시즌 최초만, 회차 유입 거부, 새 시즌 포함, 시즌 미상 번호 조작 금지, 플랫폼별 날짜 차이 보존 |
| 필터 | 빈 필터와 모두 OFF 구분, OTT 필터가 영화 제거하지 않음, KR 설정이 영국 EPL을 제거하지 않음 |
| 인증 | 공개 조회는 비개인 응답, /me와 쓰기 401, Google 서명/issuer/aud/exp 거부, sub 기준 신규 가입 경쟁 |
| 찜 | PUT 중복/DELETE 재시도, 합집합 중복 제거, 직접 저장 해제 후 작품 상속, 숨긴 분야 찜 보존 |
| 설정 | 신규 기본 movie/ott, 기존 복원, expectedVersion 경합/409, 관계+버전 원자성 |
| DB 무결성 | nullable CHECK 우회, 콘텐츠 종류/시즌 복합 FK, EPL 홈=원정, 유효하지 않은 찜 대상 |
| 공개 전 도메인 | OTT service/게임 device 최소 1, 실제 국가/IANA, 출처·origin 정합성. DDL만으로 보장한다고 오인 금지 |
| 실패·최신성 | 원천 실패 후 마지막 데이터/성공 시각 유지, DB 실패 503, fixture와 실제 수집 구분 |
| 미구현 기능 | 알림/회차/시청 이력/팀 구독이 계약에 들어오지 않음 |

읽기 전용 계약 리뷰와 실행 검사는 구분한다. 아직 runner/evidence v2/일회용 DB 적용은 없다.
DB 실행 검사는 사용자가 검사를 요청하는 구현 단계에 준비하며, 이번 문서 작성으로 테스트를 생성/실행하지 않았다.
정식 독립 handoff에는 app/backend SHA·계약 manifest·실제 migration 집합·verifier/기준 digest를 함께 고정한다.
