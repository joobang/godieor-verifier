  상한 없는 지원 범위와 기간/페이지 응답 크기를 구분한다. 미정 날짜를 임의 배치하지 않는다.

  실패 시 마지막 데이터와 성공 수집 시각 표시는 사용자 선택이다. 실행 시각·재시도·캐시 보관 상세는 별도 설계한다.
- 신규 관찰점: 페이지 전후의 중복·누락, 초기 이력 수집과 정상 갱신 구분,
  소스 미지원·일정 없음·날짜 미정·실패를 구분하고 실제 데이터와 fixture를 섞지 않는다.

제품 정책 선택을 승인된 실행 기준으로 자동 승격하지 않는다.
정확한 독립 예제·실행 절차를 검토한 뒤 별도 사용자 승인을 기록한다.

후속 답변 반영: 빈 필터=전체, 미정 별도 목록, 연기·취소 상태 표시.
설정·찜은 계정별 서버 저장 및 재로그인·재설치 복원, Google 인증 사용자의 이용과 데이터 격리를 검사 초안에 포함한다.
작품·일정 찜 모두 지원을 후속 확정했다. 실제 acceptance 파일은 계속 draft로 유지한다.

## 캘린더와 찜 후속 검사 제안

- 극장 개봉과 OTT 공개를 분리하고 EPL 단일 경기·연기/미정 kickoff를 관찰한다.
- 신규 계정 영화·OTT 기본, 기존 계정 복원, 설정에서 게임/EPL 추가와 숨김 후 찜 보존.
- 빈 필터=활성 분야 전체와 분야 모두 OFF 안내를 구분한다.
- 작품 찜+일정 찜 합집합 중복, 작품 해제 후 직접 저장 보존, 직접 저장 해제 후 상속 상태 설명.
- 지원 범위의 신규 공개 이벤트 동적 포함, 변경된 경기/공개일의 안정 ID와 찜 관계 보존.
- 월 그리드의 초과 건수와 날짜 선택 후 전체 목록, 미정 별도 목록, 색상 외 분야 구분.

세부 UI/해제 동작은 설계 제안이므로 계약/독립 검토 후 실행 가능한 기대값으로 정리한다.

## OTT 최초 공개만 · 후속 정책

OTT 회차별 공개일/완결일은 V1 수집·표시·일정 찜 대상에서 제외한다.
지역/대상 플랫폼 최초 공개 근거, 글로벌 방영일 오인 방지, 플랫폼별 날짜 차이 보존을 검사 초안에 포함한다.
시즌별 최초 공개 포함 여부는 아직 답변 전이며 기대값을 임의 확정하지 않는다.
선택한 캘린더 중심안으로 UI 관찰점을 정리한다. 승인 acceptance 파일은 변경하지 않는다.
